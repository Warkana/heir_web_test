# Heir Rus: веб-версія

Папка містить гру для браузера: `index.html`, `index.js`, `index.wasm` (35 МБ), `index.pck` та допоміжні файли. Усі вони мають лежати в одній папці.

## Запуск на своєму комп'ютері

Відкрити `index.html` подвійним кліком **не можна**: браузер не дозволяє завантажити гру з диска (`file://`). Потрібен локальний сервер.

**Windows:** двічі клікніть `запустити_локально.bat`. Потрібен встановлений Python (https://www.python.org). Відкриється браузер на `http://localhost:8060/index.html`. Щоб зупинити, закрийте вікно скрипта.

**macOS / Linux:** у Терміналі:

```
cd шлях/до/папки/web
python3 -m http.server 8060
```

Потім відкрийте http://localhost:8060/index.html у браузері.

Перший запуск довше: браузер завантажує близько 35 МБ. Далі файли беруться з кешу.

## Публікація в інтернеті

1. Завантажте всі файли папки на будь-який статичний хостинг (itch.io, GitHub Pages, Netlify, Cloudflare Pages, власний nginx).
2. Для itch.io: запакуйте вміст папки (так, щоб `index.html` був у корені архіву) у `.zip`, створіть проєкт типу «HTML», завантажте архів, увімкніть «This file will be played in the browser». Задайте розмір вікна 1280×720.
3. Спеціальні заголовки сервера не потрібні: збірка зроблена без потоків (`thread_support=false`).
4. Сервер має віддавати `.wasm` як `application/wasm` (усі згадані хостинги це роблять).

## Вимоги

- Сучасний браузер з WebGL 2: Chrome, Edge, Firefox, Safari 15+.
- Вікно гри має співвідношення 16:9 і масштабується під вікно браузера.

## Збереження

Склад бригад зберігається в пам'яті браузера (IndexedDB) для конкретного сайту. Очищення даних сайту або режим інкогніто скине його. Ресурси та прогрес походу не зберігаються між запусками.
